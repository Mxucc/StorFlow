# Security Policy

## Supported Versions

* Only the latest release of this repository is supported. Older versions and third-party builds are not covered here.

## Reporting a Vulnerability

Please report security vulnerabilities privately through GitHub's [Security Advisories](https://github.com/Mxucc/StorFlow/security/advisories/new) by opening a new draft advisory in this repository.

Please do not report security vulnerabilities through public GitHub issues, discussions, or pull requests.

Once the vulnerability is confirmed or fixed, you will receive updates through the advisory thread.
